# Calculator

This is a web-based calculator developed using HTML, CSS, and JavaScript. I built this project as part of my learning journey through The Odin Project Foundations, focusing mainly on DOM manipulation, events, and string manipulation. The layout is built primarily using Flexbox, and I adopted the color palette from the Apple Calculator for the design.

## Table of Contents
* Description
* Characteristics
* Technologies

## Description

This calculator performs basic operations such as addition, subtraction, multiplication, and division. The project demonstrates the fundamental concepts I learned through The Odin Project, using HTML for structure, CSS for styling and layout (with Flexbox), and JavaScript for the logic.

## Characteristics

* Intuitive user interface
* Support for basic arithmetic operations
* Visual feedback when buttons are pressed
* Keyboard support

## Technologies

* **HTML:** Provides the application's structure
* **CSS:** Handles styling and layout
* **JavaScript:** Implements the calculator's functionality
